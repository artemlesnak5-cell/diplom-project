## 💎 О проекте

**Tissot Luxury Watch Store** — учебный интернет-магазин наручных часов, реализованный с помощью фреймворка **Django**. Проект объединяет визуальную часть интернет-магазина и серверную логику: пользователи могут просматривать ассортимент, находить подходящие модели, добавлять товары в корзину и оформлять заказы.

Для администратора предусмотрено управление коллекциями, товарами, ценами, фотографиями, остатками и статусами заказов.

Проект разрабатывался как практическая работа по созданию многостраничного веб-приложения с авторизацией, реляционной базой данных и полноценной обработкой пользовательских действий.

> **Важно:** сайт является учебным проектом и не представляет собой официальный магазин Tissot. Демонстрационные цены и остатки не являются актуальными коммерческими предложениями.

## 🎯 Цель и задачи

**Цель:** разработать интернет-магазин товаров класса люкс на примере часового бренда Tissot с удобным интерфейсом, системой управления товарами и возможностью оформления заказов.

**Основные задачи:**

1. Спроектировать структуру страниц и интерфейс магазина.
2. Реализовать каталог, карточки товаров, поиск, фильтрацию и сортировку.
3. Создать серверное веб-приложение с помощью Python и Django.
4. Спроектировать модели базы данных для коллекций, товаров и заказов.
5. Реализовать регистрацию, авторизацию и личный кабинет покупателя.
6. Добавить корзину и оформление заказа с проверкой доступных остатков.
7. Настроить административную панель и провести тестирование.

## 🧱 Архитектура и база данных

Приложение построено на стандартном подходе **Django MVT (Model — View — Template)**:

```text
Покупатель в браузере
        │
        ▼
 HTML/CSS + Django templates
        │ HTTP-запрос
        ▼
 Django URLs → Views → Forms / Services
                        │
                        ▼
                  Django ORM
                        │
                        ▼
                    SQLite
```

**Основные модели:**

- `Category` — коллекция часов;
- `Product` — модель часов, артикул, изображение, цена и остаток;
- `Order` — заказ, получатель, адрес, общая сумма и статус;
- `OrderItem` — конкретная позиция заказа и сохранённая цена покупки;
- стандартный `User` Django — учётная запись покупателя.

## 🚀 Установка и запуск

### Требования

- Python **3.12 или 3.13**;
- `pip`;
- Windows, Linux или macOS;
- Git — по желанию, если проект скачивается через `git clone`.

### 1. Скачать проект

Скачайте репозиторий через кнопку **Code → Download ZIP** на GitHub или клонируйте его:

```bash
git clone https://github.com/artemlesnak5-cell/diplom-project
cd REPOSITORY
```

### 2. Создать виртуальное окружение

```bash
python -m venv .venv
```

**Windows (PowerShell):**

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

**Linux / macOS:**

```bash
.venv/bin/python -m pip install -r requirements.txt
```

### 3. Применить миграции и заполнить каталог

**Windows:**

```powershell
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py seed_demo
.\.venv\Scripts\python.exe manage.py createsuperuser
```

**Linux / macOS:**

```bash
.venv/bin/python manage.py migrate
.venv/bin/python manage.py seed_demo
.venv/bin/python manage.py createsuperuser
```

Команда `seed_demo` создаёт демонстрационный ассортимент. Суперпользователь создаётся отдельно для доступа в административную панель.

### 4. Запустить локальный сервер

**Windows:**

```powershell
.\.venv\Scripts\python.exe manage.py runserver
```

**Linux / macOS:**

```bash
.venv/bin/python manage.py runserver
```

Откройте в браузере **http://127.0.0.1:8000/**.

На Windows также предусмотрен файл `START_SITE.cmd` для локального запуска проекта.

В приложении есть автоматические проверки основных пользовательских сценариев. Для запуска:

```bash

```

## 🗄 База данных: SQLite и MySQL

По умолчанию сайт запускается с **SQLite** — она не требует отдельного сервера и подходит для локальной демонстрации.

Для перехода на MySQL предусмотрены настройки через файл `.env` и отдельные зависимости в `requirements-mysql.txt`. Пример параметров можно посмотреть в `.env.example`.

```ini
DB_ENGINE=sqlite
DJANGO_DEBUG=1
DJANGO_ALLOWED_HOSTS=127.0.0.1,localhost
```
